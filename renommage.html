Noms proposés

Le nom proposé est ce que l'outil a lu dans le document (titre et date). S'il est bon, « Remplacer le nom » renomme le fichier directement ; « Renommer tous » fait de même pour toute la liste. Si vous le corrigez, l'outil apprend pour les documents du même genre.

Une règle = des mots qui reviennent dans le document → un modèle de nom (ex. Facture_{numero}_{date}). Elles restent dans ce navigateur ; exportez-les pour les garder ou les partager.
